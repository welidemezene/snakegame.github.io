# snakegame.github.io# 🐍 Snake Game

A classic Snake Game built with **HTML, CSS, and JavaScript**. Simple, fun, and challenging — control the snake, eat food, grow longer, and avoid hitting the walls or yourself!

## 🚀 Features

- 🎮 Smooth keyboard controls (arrow keys)
- 🍎 Random food generation
- 🧠 Increasing difficulty as the snake grows
- 🕹️ Score tracking
- 🔁 Restart game on collision
- 📱 Responsive layout (optional)

---

## 🛠️ Tech Stack

- **HTML5** – Game canvas and structure
- **CSS3** – Basic styling
- **JavaScript (Vanilla)** – Game logic and rendering
